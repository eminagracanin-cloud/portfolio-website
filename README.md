# 👩‍💻 Personal Portfolio

> My personal portfolio website showcasing my work across **Data Science, Machine Learning, AI, and software development**.

🌐 **[View Live Portfolio →](https://eminagracanin-cloud.github.io/portfolio-website/)**

The website serves as a central overview of my technical experience, selected projects, skills, and professional background.

It was designed and developed from scratch using **HTML, CSS, and JavaScript** and is deployed through **GitHub Pages**.

---

## ✨ About the Portfolio

The portfolio highlights my work and experience across:

- 🤖 Artificial Intelligence & AI integration
- 🧠 Machine Learning
- 📊 Data Science
- ⚙️ Data & ML pipelines
- 🔌 APIs and system integration
- 💻 Software development
- 🎨 Frontend development

Selected projects link directly to their GitHub repositories, allowing the underlying code and technical implementation to be explored further.
